# AI search / GEO / AEO visibility program

## Principle
There is **no guaranteed technique** for getting recommended by ChatGPT, Gemini, Copilot or Perplexity. Improve public evidence, crawlable useful pages, entity consistency and reputable references. Google states the baseline SEO principles apply to AI search; special AI files and AI-only schema are not required.

## Evidence design for Nassli
1. Publish plain HTML facts about manufacturer scope, factory location, contact, what the team can supply, verified technology and product families.
2. Build topic-specific engineer-approved pages with clear answers, diagrams, tables and exact product references.
3. Publish legitimate case studies with permission, technical context and authentic image evidence.
4. Keep consistent brand name/URL/address/contact across website, Google profile, LinkedIn, supplier listings, YouTube, and technical download portals.
5. Give important PDFs readable titles and connected HTML landing pages. Publish IES/LDT/BIM only where files truly exist.
6. Link relevant guides, products and project showcases without doorway pages.
7. Check robots/CDN controls for search bots; review distinct policies for web search vs AI training before modifying directives.

## Prompt library and measurement
- See `tracking/ai-query-panel.csv`. Run same questions by target platform and geography/language when permitted, in a neutral, reproducible process.
- Record **observed URLs/citations**, date, engine/model/version if exposed, brand mention, competitor names, and screenshot/evidence link.
- Verify each citation URL manually. An AI-generated answer can be wrong; do not equate mention with recommendation.
- AI answer variability means single screenshots are not stable KPIs. Prefer trend across a fixed panel, plus actual referral traffic and RFQ conversion.
- Distinguish **platform analytics** (Bing/GSC where available), referral traffic, manual citations, and speculation. Never combine metrics as if they measure identical events.
- Review docs quarterly: https://developers.google.com/search/docs/appearance/ai-features ; https://platform.openai.com/docs/bots ; https://www.indexnow.org/documentation

## No shortcuts
Don't purchase guaranteed-placement schemes, fake mentions/AI reviews, mass AI-written articles, irrelevant directories, spam backlinks, unverified `llms.txt` promises or keyword stuffing.
