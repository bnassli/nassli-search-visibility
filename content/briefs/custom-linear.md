# Custom Linear Lighting — EN/AR landing page brief

**Intent:** Architects, MEP consultants and fitout contractors seeking straight/curved/ring lighting built to project measurements.

## Suggested H1
- EN: Custom Linear LED Lighting for Architectural Projects
- AR: إنارة خطية LED بتصاميم ومقاسات مخصصة للمشاريع

## Sections
1. Applications: commercial offices, retail and public spaces (only actual supported applications).
2. Customization menu: profiles, dimensions, suspension/surface/recessed, optics, color/finish — list only verified factory capabilities.
3. Controls and dimming: list per model, not universal.
4. Design package: shop drawings, photometric files and installation guide where available.
5. Real product gallery and configuration examples with correct SKUs.
6. Approved project case study references.
7. FAQ: MOQ, sample lead time, sample approvals, integration with control systems — answers approved by sales.
8. RFQ: Upload BOQ / shop drawing / dimensions + project contact.

**Evidence needed:** Actual capabilities sheet, current profiles/options, product technical reviewer.
