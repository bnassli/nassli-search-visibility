# Nassli Search & AI Visibility — مشروع تحسين ظهور نسلي

> **الحالة: مشروع عمل تأسيسي جاهز للتعاون؛ ليس نسخة الموقع الفعلية ولم يُنشر على الاستضافة أو GitHub بعد.**

هذا المستودع هو **مركز التشغيل المشترك** لتحسين حضور مصنع نسلي للإنارة (`https://nassli-led.com.sa/`) في البحث التقليدي، ونتائج البحث المعزّزة بالذكاء الاصطناعي، والخرائط، والمنصات الهندسية. يعمل عليه صاحب المشروع وCodex وClaude باستخدام Issues وPull Requests ومراجعات قابلة للتتبع.

## الهدف التجاري
رفع **عدد وجودة طلبات عروض الأسعار RFQ للمشاريع**، وليس مجرد عدد زيارات الموقع. نركّز على المهندسين والاستشاريين والمقاولين والمشتريات داخل السعودية، بالعربية والإنجليزية. لا توجد وعود بترتيب محدد أو ظهور مضمون في إجابات AI.

## ابدأ خلال دقائق

1. أنشئ مستودع GitHub **خاص Private** باسم `nassli-search-visibility` على حسابك، دون تهيئة README (لأن الملفات هنا جاهزة).
2. افتح الطرفية داخل مجلد المشروع واربطه بالمستودع، كما هو موضح في [`docs/GITHUB-SETUP.md`](docs/GITHUB-SETUP.md).
3. افتح `STATUS.md` وIssue رقم 01 من [`tracking/ISSUE-BACKLOG.md`](tracking/ISSUE-BACKLOG.md).
4. جهّز **نسخة تصدير كاملة من المصدر الحالي** أو أعطِ صلاحية قراءة لمستودع الموقع الأصلي؛ لا تنسخ بيانات العملاء أو كلمات السر إلى Git.
5. شغّل اختبار الفاحص محليًا:

```bash
python -m unittest discover -s tests -v
python -m src.nassli_audit --config config/site.json --output reports/current
```

> الأمر الثاني يتصل بالموقع العام؛ لا يمكنه العمل إذا لم يتوفر اتصال إنترنت. **هو فحص للقراءة فقط، وليس نشرًا أو تعديلًا.**

## سياسة التنفيذ

- ممنوع الكتابة المباشرة على `main` من أي وكيل. العمل على فرع `codex/seo-XXX-...` أو `claude/seo-XXX-...` لكل مهمة، وكل Issue عليها علامة `agent:codex` أو `agent:claude`.
- لا يُدمج PR دون: وصف قبل/بعد، اختبارات، تدقيق نص عربي/إنجليزي، ومراجعة بشرية عند المحتوى الفني أو الاعتمادات.
- لا نغيّر الروابط الحيّة أو نفعّل redirect/noindex/robots أو ننشر بيانات منظمة أو بيانات شركة غير مؤكدة قبل موافقة بشرية.
- لا نرفع `.env` أو مفاتيح API أو بيانات CRM أو ملفات عملاء غير مصرح بنشرها.
- أي تحسين يُقاس بخط الأساس وبالأثر على RFQ، وليس بـ«الظهور مضمون».
